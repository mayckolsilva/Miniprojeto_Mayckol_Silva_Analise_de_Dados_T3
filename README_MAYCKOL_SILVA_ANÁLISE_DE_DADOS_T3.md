
# Projeto: Análise Exploratória de Dados (AED) - Varejo

Este repositório contém uma Análise Exploratória de Dados realizada sobre uma base de dados de varejo, utilizando **Python**, **Pandas**.

---

## 🛠️ Como Executar o Projeto

Siga os passos abaixo para rodar a análise em sua máquina ou na nuvem:

1. **Baixe ou clone** este repositório.
2. Certifique-se de ter o **Python** instalado junto com as bibliotecas necessárias. Caso não as tenha, execute no terminal:

```bash
pip install pandas numpy

```

3. Posicione o arquivo **`Base Varejo.csv`** exatamente na mesma pasta onde está o notebook.
4. Abra o arquivo **`Miniprojeto_AED.ipynb`** utilizando o **VSCode** ou o **Google Colab**.
5. **Execute todas as células em ordem**:

* **No VSCode:** Clique em **"Run All"** (Executar Tudo).
* **No Google Colab:** Vá no menu superior em *Ambiente de execução* e selecione *Executar tudo*.

---

## 📂 Estrutura do Repositório

* **`Miniprojeto_AED.ipynb`** — Notebook principal contendo o código passo a passo da Análise Exploratória de Dados (AED).
* **`README.md`** — Documentação do projeto, incluindo instruções de uso, reflexão teórica sobre ETL, qualidade de dados e principais insights obtidos.
